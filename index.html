1. Introduction

This project was conducted to design the first original content for 'StreamKUS'. Rather than relying on the production team's fleeting intuition or localized trends, we aim to build a robust, universally appealing format. By analyzing a massive scale of actual viewer text data over multiple decades, we identified 'professionalism' and 'psychological strategy' as the core success factors that drive sustained audience enthusiasm. Based on these deeply empirical insights, we propose a new, integrated program format titled 'The Professional'.

2. Data Collection Process & Extracted Detailed Data

  • Data Source Justification: User reviews and ratings from the global review platform IMDb. While platforms like YouTube or Twitter provide immediate reactions, they are often fragmented, highly sensationalized, and lack structured episode-by-episode granularity. IMDb was selected as the primary source because it offers a centralized, highly structured, and historically deep repository of long-term critical viewer feedback, allowing for consistent time-series and episode-level sentiment tracking.
  • Selected Programs: Hell's Kitchen, America's Got Talent, and Survivor.
  • Selection Criteria: Targeted long-running programs with a minimum of 100 reviews and at least 50 total episodes (spanning at least 5 seasons) to ensure statistical reliability and to capture the "enduring success formula" rather than a one-off hit.
  • Total Analyzed Corpus: 1,070 valid episode-level text reviews after data cleaning (Survivor: 888, America's Got Talent: 118, Hell's Kitchen: 64).

3. Text Mining Methods & Analysis Scripts

Data Preprocessing

The raw `.xlsx` data underwent extensive preprocessing. We standardized sentiment labels, converting numeric values (-1, 0, 1) into definitive categorical data (Negative, Neutral, Positive). We deliberately stripped extraneous numerical variables such as user 'Ratings' and temporal markers like 'Seasons' during the text analysis phase. The rationale was to isolate and extract universal behavioral themes and structural program flaws that transcend specific season popularity.

Sentiment Processing & Topic Modeling (BERTopic & Codex)

To move beyond simplistic word clouds, we deployed a BERT-based (Bidirectional Encoder Representations from Transformers) model for contextual sentiment analysis at the sentence level. We combined this with OpenAI Codex to extract coherent topic clusters. Each extracted keyword was then mathematically mapped against the sentiment polarity of its source review, allowing us to generate precise percentage correlations (e.g., proving that 41.2% of all negative reviews in Hell's Kitchen specifically referenced 'Incompetence').

Automated Web Scraping & Data Structuring

This script was utilized to bypass standard pagination limits and directly query the review platform's GraphQL API. It automatically extracted thousands of user reviews, including text, ratings, and timestamps, across multiple seasons and episodes. The gathered raw data was structured into dataframes, forming the foundational dataset for our subsequent sentiment and topic modeling analyses.

    "Content-Type": "application/json",
    "User-Agent": (

def graphql(query, variables=None, max_retries=4):
    payload = {"query": query, "variables": variables or {}}
    body = json.dumps(payload).encode("utf-8")

    for attempt in range(max_retries):
        request = Request(GRAPHQL_URL, data=body, headers=HEADERS, method="POST")
        try:
            with urlopen(request, timeout=60) as response:
                data = json.loads(response.read().decode("utf-8"))
            if data.get("errors"):
                raise RuntimeError(data["errors"])
            return data["data"]
        except HTTPError as error:
            detail = error.read().decode("utf-8", errors="replace")
            if attempt == max_retries - 1:
                raise RuntimeError(f"HTTP {error.code}: {detail[:500]}") from error
        except Exception:
            if attempt == max_retries - 1:
                raise
        time.sleep(2**attempt)


def get_seasons(series_id):
    query = """
    query Seasons($id: ID!) {
      title(id: $id) {
        episodes {
          displayableSeasons(first: 100) {
            edges {
              node {
                season
                text
              }
            }
          }
        }
      }
    }
    """
    data = graphql(query, {"id": series_id})
    edges = data["title"]["episodes"]["displayableSeasons"]["edges"]
    seasons = [edge["node"]["season"] for edge in edges]
    return sorted(seasons, key=lambda value: int(value) if value.isdigit() else 10**9)


def get_episodes_for_season(series_id, season):
    query = """
    query Episodes($id: ID!, $season: String!, $after: ID) {
      title(id: $id) {
        episodes {
          episodes(first: 25, after: $after, filter: {includeSeasons: [$season]}) {
            total
            pageInfo {
              hasNextPage
              endCursor
            }
            edges {
              node {
                id
                titleText {
                  text
                }
                series {
                  displayableEpisodeNumber {
                    displayableSeason {
                      season
                      text
                    }
                    episodeNumber {
                      episodeNumber
                      text
                    }
                  }
                }
                ratingsSummary {
                  aggregateRating
                  voteCount
                }
                reviews(first: 1) {
                  total
                }
              }
            }
          }
        }
      }
    }
    """
    episodes = []
    after = None
    while True:
        data = graphql(query, {"id": series_id, "season": season, "after": after})
        conn = data["title"]["episodes"]["episodes"]
        for edge in conn["edges"]:
            node = edge["node"]
            display_no = node["series"]["displayableEpisodeNumber"]
            episodes.append(
                {
                    "episode_id": node["id"],
                    "season": display_no["displayableSeason"]["season"],
                    "episode": display_no["episodeNumber"]["episodeNumber"],
                    "episode_title": node["titleText"]["text"],
                    "episode_imdb_rating": node.get("ratingsSummary", {}).get("aggregateRating"),
                    "episode_vote_count": node.get("ratingsSummary", {}).get("voteCount"),
                    "episode_review_count": node.get("reviews", {}).get("total", 0),
                }
            )

        page_info = conn["pageInfo"]
        if not page_info["hasNextPage"]:
            break
        after = page_info["endCursor"]
        time.sleep(0.2)

    return episodes


def get_episode_reviews(episode_id):
    query = """
    query Reviews($id: ID!, $after: ID) {
          title(id: $id) {
        reviews(first: 25, after: $after, sort: {by: SUBMISSION_DATE, order: DESC}) {
          total
          pageInfo {
            hasNextPage
            endCursor
          }
          edges {
            node {
              id
              authorRating
              spoiler
              submissionDate
              summary {
                originalText
              }
              text {
                originalText {
                  plainText
                }
              }
              helpfulness {
                upVotes
                downVotes
                score
              }
            }
          }
        }
      }
    }
    """
    reviews = []
    after = None
    while True:
        try:
            data = graphql(query, {"id": episode_id, "after": after})
        except RuntimeError as error:
            if "BAD_USER_INPUT" in str(error):
                return reviews
            raise
        conn = data["title"]["reviews"]
        for edge in conn["edges"]:
            review = edge["node"]
            text = ((review.get("text") or {}).get("originalText") or {}).get("plainText")
            reviews.append(
                {
                    "review_id": review.get("id"),
                    "review_date": review.get("submissionDate"),
                    "user_rating": review.get("authorRating"),
                    "spoiler": review.get("spoiler"),
                    "review_title": (review.get("summary") or {}).get("originalText"),
                    "review_text": text,
                    "helpful_up_votes": (review.get("helpfulness") or {}).get("upVotes"),
                    "helpful_down_votes": (review.get("helpfulness") or {}).get("downVotes"),
                    "helpfulness_score": (review.get("helpfulness") or {}).get("score"),
                }
            )

        page_info = conn["pageInfo"]
        if not page_info["hasNextPage"]:
            break
        after = page_info["endCursor"]
        time.sleep(0.2)
    return reviews


def score_text_sentiment(text):
    text = (text or "").lower()
    positive_words = {
        "great",
        "good",
        "excellent",
        "amazing",
        "best",
        "love",
        "loved",
        "enjoy",
        "enjoyed",
        "fun",
        "interesting",
        "perfect",
        "strong",
        "iconic",
        "legendary",
        "fantastic",
        "solid",
    }
    negative_words = {
        "bad",
        "boring",
        "worst",
        "awful",
        "terrible",
        "poor",
        "hate",
        "hated",
        "disappointing",
        "weak",
        "slow",
        "dull",
        "predictable",
        "annoying",
        "mess",
        "waste",
    }
    words = re.findall(r"[a-z']+", text)
    score = sum(word in positive_words for word in words) - sum(word in negative_words for word in words)
    if score > 0:
        return "positive"
    if score < 0:
        return "negative"
    return "neutral"


def classify_sentiment(rating, text):
    if pd.notna(rating):
        rating = int(rating)
        if rating >= 7:
            return "positive"
        if rating <= 4:
            return "negative"
        return "neutral"
    return score_text_sentiment(text)


def main(series_id=SERIES_ID, output_excel=OUTPUT_EXCEL):
    seasons = get_seasons(series_id)
    print(f"시즌 {len(seasons)}개 확인: {', '.join(seasons[:10])} ... {seasons[-1]}", flush=True)

    episodes = []
    for season in seasons:
        season_episodes = get_episodes_for_season(series_id, season)
        episodes.extend(season_episodes)
        print(f"시즌 {season}: 회차 {len(season_episodes)}개", flush=True)
        time.sleep(0.2)

    rows = []
    total_episodes = len(episodes)
    for index, episode in enumerate(episodes, start=1):
        if not episode.get("episode_review_count"):
            print(
                f"{index}/{total_episodes} "
                f"S{episode['season']}E{episode['episode']} {episode['episode_id']}: 리뷰 0개",
                flush=True,
            )
            continue

        reviews = get_episode_reviews(episode["episode_id"])
        for review in reviews:
            row = {**episode, **review}
            row["sentiment"] = classify_sentiment(row.get("user_rating"), row.get("review_text"))
            rows.append(row)
        print(
            f"{index}/{total_episodes} "
            f"S{episode['season']}E{episode['episode']} {episode['episode_id']}: 리뷰 {len(reviews)}개"
            ,
            flush=True,
        )
        time.sleep(0.25)

    columns = [
        "season",
        "episode",
        "episode_id",
        "episode_title",
        "episode_imdb_rating",
        "episode_vote_count",
        "episode_review_count",
        "review_id",
        "review_date",
        "user_rating",
        "sentiment",
        "spoiler",
        "review_title",
        "review_text",
        "helpful_up_votes",
        "helpful_down_votes",
        "helpfulness_score",
    ]
    df = pd.DataFrame(rows, columns=columns)
    if not df.empty:
        df["season"] = pd.to_numeric(df["season"], errors="coerce")
        df["episode"] = pd.to_numeric(df["episode"], errors="coerce")
        df["review_date"] = pd.to_datetime(df["review_date"], errors="coerce")
        df = df.sort_values(["season", "episode", "review_date"], ascending=[True, True, False])

    df.to_excel(output_excel, index=False)
    print(df.shape)
    print(df.head(10).to_string(index=False))
    print(f"저장 완료: {output_excel}")


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--series-id", default=SERIES_ID)
    parser.add_argument("--output", default=OUTPUT_EXCEL)
    args = parser.parse_args()
    main(series_id=args.series_id, output_excel=args.output)

            count = neg_reviews['review_text'].str.contains(eng_kw, case=False, na=False).sum()
        neg_counts[label_en] = count
        neg_results[label_en] = (count / total_neg * 100) if total_neg > 0 else 0

    # Structuring and Sorting DataFrames
    df_pos_kw = pd.DataFrame(list(pos_results.items()), columns=['Factor', 'Percentage'])
    df_pos_kw['Count'] = df_pos_kw['Factor'].map(pos_counts)
    df_pos_kw = df_pos_kw.sort_values(by='Percentage', ascending=True)

    df_neg_kw = pd.DataFrame(list(neg_results.items()), columns=['Factor', 'Percentage'])
    df_neg_kw['Count'] = df_neg_kw['Factor'].map(neg_counts)
    df_neg_kw = df_neg_kw.sort_values(by='Percentage', ascending=True)

    # Draw Horizontal Bar Charts
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(18, 5))

    # Top 10 Positive Factors Chart
    bars1 = ax1.barh(df_pos_kw['Factor'], df_pos_kw['Percentage'], color='royalblue')
    ax1.set_title(f"{name} - Top 10 Positive Factors", fontsize=13, fontweight='bold')
    ax1.set_xlabel('Appearance Rate in Positive Reviews (%)', fontsize=11)
    ax1.set_xlim(0, df_pos_kw['Percentage'].max() + 22)

    # Top 10 Negative Factors Chart
    bars2 = ax2.barh(df_neg_kw['Factor'], df_neg_kw['Percentage'], color='crimson')
    ax2.set_title(f"{name} - Top 10 Negative Factors", fontsize=13, fontweight='bold')
    ax2.set_xlabel('Appearance Rate in Negative Reviews (%)', fontsize=11)
    ax2.set_xlim(0, df_neg_kw['Percentage'].max() + 22)

    # Add Data Labels (Skip for blank items)
    for bar, count, label in zip(bars1, df_pos_kw['Count'], df_pos_kw['Factor']):
        if label.strip() != '':
            width = bar.get_width()
            ax1.text(width + 0.5, bar.get_y() + bar.get_height()/2, f'{width:.1f}% ({count})',
                     va='center', ha='left', fontsize=9, fontweight='bold')

    for bar, count, label in zip(bars2, df_neg_kw['Count'], df_neg_kw['Factor']):
        if label.strip() != '':
            width = bar.get_width()
            ax2.text(width + 0.5, bar.get_y() + bar.get_height()/2, f'{width:.1f}% ({count})',
                     va='center', ha='left', fontsize=9, fontweight='bold')

    plt.tight_layout()
    plt.show()

5. Content Proposals (Integrated Ecosystem)

Rather than merely listing these insights, we propose 'The Professional' as an integrated survival ecosystem. By combining the proven success elements while structurally eliminating the failure points, we create a program where dramatic tension arises naturally from the participants rather than artificial direction.

Participant Composition (Elimination of Incompetence)

Addressing the major flaw in Hell's Kitchen (41.2% negative feedback regarding incompetent cast members), our show will strictly recruit seasoned professionals with over 10 years of industry experience. This ensures "flawless performances by the best," aiming for the 95.1% high satisfaction rate observed in AGT.

Autonomous System (Blocking Production Intervention)

To directly counter the highest source of dissatisfaction in Survivor (33.6% negative feedback for excessive producer intervention), the authority to eliminate participants will be delegated entirely to the contestants themselves through an autonomous voting council. This induces a pure strategic battle free from artificial manipulation.

Subdued Production (Focusing on the Essence)

Incorporating feedback on AGT's 'excessive audience reactions' (41.4%) and 'forced melodrama' (20.7%), we will eliminate emotional editing. The program will adopt a documentary-style realism that focuses squarely on the technical craftsmanship and strategic moves of the professionals.

Symbolism (Providing Catharsis)

Mirroring Hell's Kitchen's success factor, the 'black jacket' (31.4% positive), we will award specially crafted uniforms and tools to survivors. This provides visual catharsis and reinforces the program's core theme of professional authority.

6. Conclusion

Summary of Core Findings and Proposals

This project empirically demonstrated the success formulas and failure factors of survival programs by analyzing 1,070 text reviews from IMDb. The analysis revealed that viewers responded highly positively to overwhelming professionalism and sophisticated participant strategies, while showing strong aversion to participant incompetence and artificial production interventions. Based on these findings, we propose a new content model, 'The Professional', an integrated survival ecosystem that combines the recruitment of seasoned experts with an autonomous council system to reflect the core empirical needs of the audience.

Limitations of the Analysis

There were practical limitations during the research process. First, due to a lack of detailed reviews for specific individual episodes, we had to adopt an integrated program-level analysis rather than the initially planned episode-specific sentiment tracking. Second, utilizing data solely from the single platform IMDb introduces the possibility that the results are skewed toward the tendencies of a specific Western-centric user base.

Future Directions

It is necessary to collect additional data from YouTube trending features and social media platforms to dynamically reflect real-time public reactions. Furthermore, a comparative analysis with popular domestic programs like 'Culinary Class Wars' could help derive localized strategies tailored to different cultural contexts. Ultimately, introducing episode-level time-series sentiment analysis to track text characteristics at specific viewership fluctuation points will provide more concrete, data-driven production guidelines.
